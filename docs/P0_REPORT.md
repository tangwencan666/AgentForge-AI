## 2 需要确认的核心决策

1. 四个角色槽位独立配置，真实调用按服务端角色路由；Mock 全程明示，模型失败不自动换成模拟响应。
2. FastAPI 管身份与业务 API；LangGraph 管工作流；LangChain 加适配器管模型和检索；React 展示六个 Center。
3. PostgreSQL 保存状态、检查点、审批、事件、预算和幂等账本；Redis Streams 管异步调度，不作为唯一真相源。
4. 所有工具调用经过 Tool Gateway。Reviewer 只能给审查意见，高风险动作需权限与有效人工审批同时满足。
5. Docker Sandbox 由独立可信 Runner 管理，none 网络、非 root、只读根、资源限额、cap_drop ALL、seccomp 和 no-new-privileges 为固定政策。Docker 不可用或政策无法生效时禁止执行，绝不回退宿主机。
6. 预热采用未执行任务容器的有限池，默认 2 个预热、4 个活跃、6 个总容器；单次租赁后销毁。执行前重置并验证空状态，不复用执行过不可信代码的容器。
7. Skills 自我进化仅生成候选；安装、启用和依赖变更需要人工审批，不能自行下载安装或获得额外权限。
8. 上下文含来源和 ACL，模型调用前原子预留 Token 与预算；SSE 可重连且不触发重新执行，成本区分实测、估算、未决及 Mock。

初始限额、池大小和保留期是拟实施配置，后续按真实环境测量调整，管理员不能以演示需要绕过安全禁令。Docker 共享内核，不能保证绝对安全。
