# AgentForge AI 自动化验收标准

本文件规定未来测试的输入、断言和证据。本轮不编写或运行应用测试，没有测试通过声明。P0 文档检查不能替代 P1 至 P6 的自动化与真实环境验证。

## 1 测试分层与门禁

单元和协议测试使用明确的测试替身，验证业务契约、权限、路由、状态、脱敏和计量。持久化集成测试启动独立 PostgreSQL、Redis；Docker 隔离测试必须使用真实 Linux Docker Engine 和实际批准镜像。前端 E2E 采用浏览器测试验证页面、授权和 SSE。

测试工具计划采用 pytest、异步 HTTP 测试、供应商 HTTP stub、实际数据库服务以及 Playwright。P1 锁定版本。CI 的隔离测试使用专用可销毁执行节点，不把 CI 的高权限、宿主目录或 Docker Socket 交给任务容器。测试数据库、容器和外部副作用都带测试范围标识。

Docker 可用的安全门禁中，隔离测试缺环境、skip、xfail、政策不支持或未确认清理均视为门禁失败；Docker 不可用时的 Fail Closed 测试可以独立运行，但不能替代真实隔离测试。测试报告记录版本、镜像 digest、策略版本、测试 ID、实际断言和清理结果，不保存秘密原值。

## 2 原始十项验收映射

| ID | 用户要求 | 自动化场景 | 必须断言 | 阶段 |
| --- | --- | --- | --- | --- |
| A01 | 四模型路由正确 | 每槽位配置不同 stub 标识，走完整 Planner/Worker/Reviewer；再参数化同商多模型与四商组合 | 节点角色、provider、model、配置版本对应；停用必需槽位明确报错，无隐式替换 | P1/P2 |
| A02 | API Key 不泄露 | 注入随机金丝雀 Key；配置、健康检查、成功、异常、流式断流和导出；扫描日志、SSE、追踪、检查点、前端缓存与 Git | Key、Authorization 和常见编码变体不出现于持久日志及前端响应；秘密只在写入和授权模型请求边界出现 | P1/P5/P6 |
| A03 | 单模型失败正确处理 | 四角色分别触发 401、429、5xx、超时、错误结构及 Reviewer 故障 | 非重试错误不重试；重试计限额；必需失败不报成功；可选分支降级明示；不切 Mock | P1/P2 |
| A04 | 任务超时和取消 | 排队、模型流式、工具调用、沙箱运行、等待审批分别取消/超时，服务重启再检查 | 停止新调用、终态不回退、审批失效、健康节点沙箱 5 秒内确认停止；失联标记清理未确认 | P2/P3 |
| A05 | 无授权不能执行高风险工具 | 无权限、缺批准、批准过期、跨租户、伪造 approved、批准后改参数或撤销权限 | 外部测试服务器副作用计数为 0；审计含拒绝原因；Reviewer “通过”不改变结果 | P2/P4 |
| A06 | 沙箱无外网访问 | 真实容器尝试访问受控外部 HTTP/DNS、直接 IP、IPv6、宿主网关、metadata 和其他容器 | 连接全部失败且受控探针收不到请求；inspect 显示 none，无非回环网络；不靠目标本身离线判通过 | P3 |
| A07 | 沙箱不可访问宿主敏感目录 | 宿主测试目录放随机标记，容器尝试 Windows/Linux 目标路径、路径穿越和挂载；检查设备及 Socket | 读不到标记；无宿主 bind、Socket、设备；篡改安全字段拒绝；测试不读取真实私人秘密 | P3 |
| A08 | 沙箱任务间无状态泄露 | A 写文件、修改环境、启动子进程；B 同租户和另一租户运行；预热启停均覆盖 | B 无 A 标记或进程，execution_id/容器/工作区互异；A 已销毁，B 未获 A 租约；并发租赁唯一 | P3 |
| A09 | Docker 不可用安全失败 | 无 endpoint、拒绝连接、daemon 失联、镜像缺失、seccomp/cgroups 不支持 | 返回明确不可用/政策错误；宿主 subprocess 哨兵未触发；无未隔离执行；失联节点不接受新任务 | P3 |
| A10 | 模型调用成本可统计 | 固定输入输出/缓存/推理 usage、Decimal 单价、重试、并发、断流和未知 usage | 精确计算及分类，无双算；按角色/任务/租户汇总一致；估算/未决标识明确；Mock 单列 | P1/P2/P5 |

金丝雀扫描不得输出命中的秘密字符串，只返回位置与违规类型；测试提交不包含真实 API Key。

## 3 协作状态与恢复补充验收

| ID | 场景 | 必须断言 |
| --- | --- | --- |
| B01 | 无依赖 Coder/Researcher 使用控制屏障同时运行；有依赖和共享写资源场景 | 无依赖确实重叠，有依赖严格等待，共享写冲突串行，按 node_id 结果汇聚无丢失 |
| B02 | Planner 输出环、无效角色、越权目标、非法输出引用 | 服务端在执行任何工具前拒绝，计划不能自授权限 |
| B03 | Reviewer 连续要求修订、结构修复和模型重试 | 达迭代/调用/Token/预算上限即终止，恢复和审批不清零计数 |
| B04 | 两个付费分支竞争最后剩余额度 | 原子预留阻止超卖，仅有可支付调用发出，失败预留按规则对账 |
| B05 | 在数据库提交、Redis 发出、外部副作用、结果提交之间分别杀 Worker | outbox 不丢调度，重复投递不重复已完成操作；未知外部结果进入 needs_reconciliation |
| B06 | Worker 租约过期后仍尝试调用和提交，新 Worker 已接管 | stale fencing token 被 Gateway/Runner/数据库拒绝，不覆盖新结果 |
| B07 | 审批中重启服务、多审批分支、重复/越权恢复 | 位置和审批持久化；按操作标识恢复；审批前无副作用；重复决定不能二次执行 |
| B08 | Redis 重启、PostgreSQL 短暂不可用 | 任务从数据库恢复，批准/预算不丢；无法校验状态时禁止新副作用 |
| B09 | 重复 Idempotency-Key，同 key 不同请求体 | 同租户同载荷返回同任务，不同载荷冲突，跨租户不泄露已有任务 |
| B10 | 取消与成功响应同时发生，迟到事件与结果重放 | 按状态版本确定唯一终态，取消后不能出现新工具调用 |

## 4 Docker 与预热补充验收

| ID | 场景 | 必须断言 |
| --- | --- | --- |
| C01 | 运行 id、写只读根、能力/提权探针、检查 seccomp 与 NoNewPrivs | UID 非 0、根写失败、capabilities 为空、no-new-privileges 生效、seccomp启用；无 unconfined |
| C02 | 有限 CPU 忙循环、受控内存增长、受控进程增长及 tmpfs/输出超额 | CPU 配额、内存硬限、pids 与空间上限生效，记录 OOM/limit 原因；不危及共享主机 |
| C03 | 任务退出、异常、超时、取消、Runner 崩溃及删除失败 | 整容器进程终止、资源删除可核实；失败隔离告警；不误删非本系统容器 |
| C04 | 预热 2 个、并发 4 个、总容量 6 个、每租户 2 个，时钟推进过 TTL | 无超配，隔离未清理容器占容量，空闲容器回收，租约唯一且带 fencing |
| C05 | 污染未使用池成员文件/进程或篡改实际参数，再租赁 | 执行前检查失败即销毁，不把不明状态成员投入任务；新建失败安全拒绝 |
| C06 | 预热关闭、池为空、不同用户连续租赁 | 一次性容器策略一致，已执行容器不回池，跨用户工作区互不共享 |
| C07 | 输入/产物含 ..、绝对路径、symlink、hardlink、设备及压缩炸弹 | 注入/导出拒绝逃逸与超额，不在宿主文件系统解压不可信路径 |
| C08 | 任务 stdout/stderr 打印金丝雀和大文件文本 | 摘要限制、脱敏先于持久化，敏感模式禁存文本；Docker 原始输出日志不持久化 |
| C09 | 核对成功、未启动、超时和失联记录 | task_id、execution_id、code_hash、timeout、exit_code、摘要、resource_usage、created_at 齐全；不可得值为 null 加原因 |
| C10 | 同一负载下预热开启与关闭 | 策略不变；记录创建/排队/总延迟与命中率，不用关闭安全项换取指标 |

宿主隔离探针使用一次性测试标记目录，路径攻击仅针对测试资源，不用真实 SSH Key、用户文档或生产数据做试验。所有压力场景有测试层总期限和节点资源上限。

## 5 工具技能上下文与前端验收

| ID | 场景 | 必须断言 |
| --- | --- | --- |
| D01 | 未注册工具、额外参数、非法 URL/路径/资源 ID、跨租户工具 | 白名单/Schema/语义授权拒绝，下游未被调用；不能绕 Gateway |
| D02 | 远程 MCP token 受众不符、endpoint 变更、超时和配额耗尽 | 认证及端点拒绝，无 token 任意透传；超时有未决状态而非假定回滚 |
| D03 | Agent 生成 Skill 候选，尝试自行下载安装和提权 | 候选只作为数据注册，下载/安装/执行哨兵未触发，权限声明不授予能力 |
| D04 | Skill 安装、启用、升级、依赖变化、撤销 | 安装启用均绑定有效人工批准，哈希/依赖变化需重新批准；新调用被禁用状态阻止 |
| D05 | RAG 文档注入指令、跨租户检索、不同 ACL 缓存命中 | 不改变政策/审批，不能检索或缓存命中越权内容，引用来源可追踪 |
| D06 | 超长上下文、摘要失败、embedding usage | 裁剪后含输出预留且不超窗口；缺失证据标明，摘要/embedding 成本不遗漏 |
| D07 | 六页面正常、失败、权限不足、无 Docker、Mock/mixed 模式 | 所有页面可达，权限由服务端拒绝，状态准确，Mock 标签可见，Key 不回显 |
| D08 | SSE 断线重连、Last-Event-ID、事件保留期、权限撤销 | 回放范围正确且序号可去重，过期转快照，重连不重执行，撤销后流停止 |
| D09 | 日志/遥测采集模型异常、工具错误和高风险拒绝 | 关联 ID 完整且无默认机密内容；高风险预调用审计失败时副作用为 0 |
| D10 | 成本/延迟/错误聚合、其他租户查询、未知 usage | 聚合准确且授权过滤，显示原币种/价格版本/估算状态，未决不记零 |

## 6 证据与发布判定

每项记录测试名称、环境、执行时间、观察值、expected/actual、通过/失败/未运行及原因。协议 stub 不证明真实供应商可用，需在受控测试账号与预算内另做真实适配烟测；真实烟测不向日志写秘密。真实 Docker 门禁不能在 Mock 环境宣称完成。

发布阻断项包括：任何秘密泄露、权限绕过、宿主执行回退、网络或宿主文件隔离失败、任务状态残留可跨租户读取、无有效审批执行高风险操作、预算并发超卖，以及无法确认的执行清理。性能目标根据实测提出，安全项不得为演示或性能让步。
